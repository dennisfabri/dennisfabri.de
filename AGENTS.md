# AGENTS.md — dennisfabri.de

Personal website for [dennisfabri.de](https://www.dennisfabri.de), focused on JAuswertung (competition scoring software for DLRG lifesaving sport). Built with Jekyll and deployed as a static site.

## Directory Layout

```
.
├── web/                  # Jekyll site (content + build config)
├── ergebnisse/           # Static results archive (bundled into build)
├── punkterechner/        # TypeScript score calculator (compiled into web)
├── private/              # Deployment secrets (not in git)
├── build-production.sh   # Top-level build script (Linux)
├── build-production.cmd  # Top-level build script (Windows)
├── reduce-site-css.cmd   # Windows utility: strips unused CSS via uncss
├── setup-linux.sh        # One-time setup for Linux
└── setup-windows.cmd     # One-time setup for Windows
```

### `web/` — Jekyll Site

Static site built with Jekyll. Source files live here; the compiled output goes to `build/www/`.

- `_config.yml` — main Jekyll config (site title, URL, plugins, permalink format)
- `_config_development.yml` — overrides for local dev (localhost URLs)
- `_config_production.yml` — overrides for production builds
- `_posts/` — blog posts (date-prefixed Markdown, e.g. `2026-07-01-*.md`)
- `pages/` — static pages organized by section (`home/`, `jauswertung/`, `rettungssport/`, `anleitungen/`, `ergebnisse/`)
- `_docs/` — Jekyll collection for standalone docs pages (permalink: `/docs/:path`)
- `_layouts/` — page templates (`default.html`, `page.html`, `post.html`)
- `_includes/` — reusable HTML partials (head, header, footer, navigation, sidebar)
- `_data/navigation.yml` — top navigation bar entries (edit here to add/remove nav items)
- `_data/toc.yml` — sidebar table of contents
- `_plugins/` — Jekyll plugins (external links)
- `assets/` — CSS, JS, images, fonts, favicons
- `Gemfile` — Ruby gem dependencies (Jekyll, plugins)
- `package.json` — npm dependencies (Bootstrap 5, FontAwesome)
- `build-production.sh` — runs `bundle exec jekyll build` with production config

**Key generated files (do not edit manually):**
- `web/assets/js/calculator.bundle.js` — compiled from `punkterechner/`
- `web/assets/js/chart.umd.js` — copied from `punkterechner/node_modules`
- `web/pages/rettungssport/punkterechner.md` — generated by `punkterechner/build.pl`

### `ergebnisse/` — Results Archive

PHP pages with historical competition results (DEM, DSM, DMM). Copied verbatim into `build/ergebnisse/` during the production build. Not processed by Jekyll.

- `dem/`, `dsm/`, `dmm/` — result data by competition type
- `*.php` — result display pages (require a PHP-capable server; cannot be previewed with `jekyll serve`)
- `.htaccess` — Apache config for the results subdirectory

### `punkterechner/` — Score Calculator

Small standalone TypeScript application that calculates DLRG lifesaving sport scores. Built separately and integrated into the Jekyll site.

- `src/ts/` — TypeScript source files (compiled in a specific order defined in `build.pl`)
- `src/html/` — HTML template for the standalone calculator page
- `src/md/` — Markdown page that gets injected into Jekyll (`punkterechner.md`)
- `build.pl` — Perl build script: compiles TypeScript via `tsc`, bundles JS files in order, copies outputs to `web/assets/js/` and `web/pages/rettungssport/`
- `tsconfig.json` — TypeScript compiler config
- `package.json` — npm deps (chart.js, typescript, http-server)
- `build/` — intermediate build output (gitignored)

**Bundle order** (defined in `build.pl`): Types → Sexes → Record → Discipline → Agegroup → Year → Calculator → TimesHistory → Controller → RecordsHistory → Rechner

### `private/` — Deployment Secrets

Contains files needed for the live site that must not be committed to git. Copied to `build/www/` at the end of the production build. The directory itself is gitignored (`/private/`).

Currently contains: `ahrefs_*` verification file.

## Build

### Ruby Version

The project uses **system Ruby** (3.3.x). Gems are installed into `web/vendor/bundle/` via the global bundler setting `BUNDLE_PATH: "vendor/bundle"` (set in `~/.bundle/config`). No rbenv or rvm required.

### Setup (once)

```sh
# Linux
./setup-linux.sh        # installs rbenv Ruby 3.4.1, Jekyll, Bundler, minify, typescript

# Windows
setup-windows.cmd
```

### Development

```sh
# Run Jekyll dev server (from web/)
cd web
bundle exec jekyll serve --config _config.yml,_config_development.yml

# Run punkterechner standalone (from punkterechner/)
cd punkterechner
npm start               # serves build/ on localhost:8080
```

### Production Build

```sh
./build-production.sh
```

This script:
1. Cleans `build/`
2. Runs `punkterechner/build.pl` — compiles TypeScript, bundles JS, copies artifacts into `web/`
3. Runs `web/build-production.sh` — Jekyll production build to `build/www/`
4. Copies `ergebnisse/` into `build/ergebnisse/`
5. Minifies HTML, JS, CSS, SVG in `build/`
6. Copies `private/` contents into `build/www/`

Output: `build/www/` (web root) + `build/ergebnisse/`

### CSS Optimization (Windows only)

`reduce-site-css.cmd` runs `uncss` against the build output to strip unused CSS rules. Run it after a production build when CSS has changed significantly.

## Content

### Adding a Blog Post

Create `web/_posts/YYYY-MM-DD-slug.md` with this frontmatter:

```yaml
---
layout: post
title: JAuswertung 2026 (18.1.0)
date: 2026-07-01 10:00
category: JAuswertung
author: Dennis Fabri
tags: [JAuswertung]
summary:
---
```

All fields are required. Posts follow the permalink pattern `/:year/:month-:day-:slug.html`.

### Navigation

Top nav entries are in `web/_data/navigation.yml`. Add an entry there to make a new section appear in the header.

### The `punkterechner` Page

The score calculator page at `web/pages/rettungssport/punkterechner.md` is **generated** — do not edit it directly. Edit `punkterechner/src/md/punkterechner.md` and re-run `punkterechner/build.pl`.

### `_docs` Collection

Pages under `web/_docs/` are served at `/docs/:path`. They use the `page` layout and are separate from the `pages/` section.
